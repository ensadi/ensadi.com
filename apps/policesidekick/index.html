Police Sidekick is a legal reference tool designed for law enforcement officers. This web application provides access to legal reference materials offline.

Features:

  • Offline access to legal reference materials
  • Search datasets
  • Free downloadable content

Contributing: We welcome contributions to Police Sidekick! You can help by providing feedback, reporting issues, or contributing new datasets. Please submit any contributions or issues through our GitHub issues.

Privacy: This app runs entirely in your browser. No data is sent to any server except for downloading datasets from ensadi.com.

Terms: By using this application, you agree to the terms of service at ensadi.com.
