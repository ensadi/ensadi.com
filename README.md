# ensadi.com

## Projects

- `apps/policesidekick/` — Police Sidekick PWA app
- `ensadi/` — site content and dataset assets

## Local server

```bash
make start
```

Then open `http://localhost:8000`.

## Contributing

We welcome contributions to Police Sidekick! You can help by providing feedback, reporting issues, or contributing new datasets. Please submit any contributions or issues through our [GitHub issues](https://github.com/ensadi/ensadi.com/issues).

### Tests

Run Playwright end-to-end tests from the repo root:

```bash
make test
```

HTML report is generated under `tests/results/html-report`.
